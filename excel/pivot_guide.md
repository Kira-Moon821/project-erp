> 配套文件：`ERP经营分析_数据源.xlsx`（18 个工作表）、`pivot_macro.bas`（一键生成真透视表的 VBA 宏）
> 口径来源：`docs/数据字典与业务口径.md` —— 本页所有指标口径与该文档**完全一致**

---

## 0. 先说清楚：你现在打开的是什么

这份工作簿里**已经有一层透视分析结果**，分三种形态，作用不同：

| 工作表 | 形态 | 是否随数据变动自动更新 | 用途 |
|---|---|---|---|
| `透视预分析` | **SUMIFS / COUNTIFS 公式** | 会（改数据自动重算） | 讲"公式版透视"——Excel 底层本质 |
| `透视结果_品类营收` / `_客户结构` / `_月度趋势` / `_漏斗与AI` | **静态预聚合结果** | 不会（Python 预先生成） | 讲"数仓预聚合层"——面试官能直接看到数字 |
| `真透视表` | **真·数据透视表对象** | 会 | 讲"交互式透视"——需按下方步骤生成 |

**为什么默认不是真透视表？**
本机的 Microsoft Excel 处于 **Office 许可过期（只读 / 缩减功能模式）**：通过 COM 写入单元格与另存为均被系统拒绝，
因此无法在交付前自动生成真正的 PivotTable 对象。

**三种补救方式任选其一（按省事程度排序）：**

- **方式 A（推荐，30 秒）**：激活 Office → 按下文第 1 节运行宏 → 自动得到 8 个真透视表
- **方式 B（不激活 Office，5 分钟）**：按下文第 2 节手动做 1 个透视表，剩下 7 个照抄参数
- **方式 C（零操作）**：直接用 `透视结果_*` 页 + `透视预分析` 页，面试时讲"预聚合层 + 公式层"的设计

> 激活 Office 也很简单：打开任意 Office 组件 → 账户 → 登录有许可证的账号，或输入密钥。
> 激活后本目录下的 `scripts/build_pivot.ps1` 也能一键生成（PowerShell + COM 版）。

## 1. 方式 A：运行宏一键生成 8 个真透视表

### 步骤

1. 打开 `ERP经营分析_数据源.xlsx`
2. `Alt + F11` 打开 VBA 编辑器
3. 菜单 **文件 → 导入文件…** → 选择 `excel/pivot_macro.bas` → 打开
4. 回到 Excel，`Alt + F8`（或开发工具 → 宏）→ 选 `BuildAllPivots` → **运行**
5. 完成后会自动新建工作表 **`真透视表`**，里面有 8 个透视表

### 生成的 8 个透视表

| # | 透视表 | 源数据表 | 行字段 | 值字段 | 页面筛选 |
|---|---|---|---|---|---|
| 1 | `pt_category` 品类营收 | 商品销售明细 | 品类 | 营收、毛利、销量 | — |
| 1b | ↳ 计算字段 | | | **毛利率** = 毛利 ÷ 营收 | |
| 2 | `pt_brand` 品牌×品类 | 商品销售明细 | 品牌、品类 | 营收、毛利 | — |
| 3 | `pt_customer` 客户结构 | 订单明细表 | 客户层级、行业 | 净营收、订单数 | 订单状态 = 已完成 |
| 4 | `pt_monthly` 月度趋势 | 订单明细表 | 年月 | 净营收、订单数、毛利 | 订单状态 = 已完成 |
| 5 | `pt_funnel` 商机漏斗 | 线索商机 | 阶段 | 商机数、商机金额、AI辅助数 | — |
| 5b | ↳ 计算字段 | | | **AI辅助占比** | |
| 6 | `pt_channel` 渠道效率 | 营销投放 | 渠道 | 投放成本、归因收入、线索数、ROAS | — |
| 7 | `pt_ai` AI 使用效能 | AI使用记录 | 场景 | AI调用次数、采纳次数、节省工时 | — |
| 7b | ↳ 计算字段 | | | **AI采纳率** | |
| 8 | `pt_inventory` 库存健康 | 库存快照 | 仓库、品类 | 库存金额、缺货量、在库量 | — |

### 另外两个辅助宏

| 宏 | 作用 |
|---|---|
| `ExportPivotCsv` | 把 8 个透视表导出为 CSV 到 `excel/pivot_output/`，用于与静态页交叉核对 |
| `VerifyAgainstStatic` | 自动比对 `pt_category` 与 `透视结果_品类营收` 的营收合计，差异 < 1 元判为通过 |

> ⚠️ **编码提醒**：`pivot_macro.bas` 是 **GBK 编码**（VBA 编辑器按系统 ANSI 代码页读取，用 UTF-8 会中文乱码）。
> 若要用文本编辑器阅读，另存一份 UTF-8 副本：`pivot_macro_utf8.bas.txt`。
> **不要**把 UTF-8 版本再导入回 Excel。

## 2. 方式 B：手动做一个透视表（3 步）

以 **「品类营收透视」** 为例，其余 7 个同法：

### 第 1 步：选源数据

1. 切到工作表 **`商品销售明细`**
2. 点任意单元格 → `Ctrl + Shift + End` 选中整个数据区（含表头）
3. 菜单 **插入 → 数据透视表**
4. 弹窗里：
   - 位置选 **新工作表**
   - 点 **确定**

### 第 2 步：拖字段

右侧「数据透视表字段」面板：

- 拖 **`category`**（品类）→ **行**
- 拖 **`revenue_amount`**（营收）→ **值**
- 拖 **`gross_profit`**（毛利）→ **值**
- 拖 **`qty`**（销量）→ **值**

> 三个值字段默认是"求和"，符合预期。鼠标左键拖进去就是求和，右键才是"计数/平均值"。

### 第 3 步：加计算字段「毛利率」

1. 透视表任意单元格右键 → **值字段设置**（或 **计算字段**）
2. 名称填 `毛利率`，公式填：

   ```
   =IFERROR([毛利]/[营收],0)
   ```

3. 确定，右上角字段列表会出现 `毛利率`，把它拖进 **值**

### 排版建议（加分项）

- 透视表 **设计 → 报表布局 → 以表格形式显示**（`xlTabularRow`）
- 设计 → 透视表样式选一个内置样式（宏里已自动设为 `PivotStyleMedium9`）
- 加 **值字段设置 → 数字格式**：营收/毛利 `#,##0.00`，销量 `#,##0`
- 切片器：`分析 → 插入切片器` → 放 `customer_tier`，做交互筛选

## 3. 口径对照（**这一节是面试重点**）

| 指标 | 口径定义 | 本工作簿实现 |
|---|---|---|
| 营收 | `net_amount` 求和，仅 `order_status = 已完成`；**已退货订单不计入** | 透视表页面字段筛选 `order_status = 已完成` + 商品明细表本身已排除退货行 |
| 毛利 | `gross_profit` 求和 | 值字段直接求和 |
| 毛利率 | 毛利 ÷ 营收 | 计算字段 `=IFERROR([毛利]/[营收],0)` |
| 客单价 | 营收 ÷ 订单数 | 计算字段 |
| 缺货量 | `stock_gap` 求和（= 安全库存 − 在库量，正数代表缺货） | 值字段 |
| 库存金额 | `inventory_value` 求和 | 值字段 |
| 商机数 | `lead_id` 计数 | 值字段选**计数**（不是求和） |
| AI 辅助占比 | AI 辅助商机数 ÷ 商机数 | 计算字段 |
| ROAS | 归因收入 ÷ 投放成本 | 源表已有 `roas` 列，也可用计算字段复算 |
| AI 采纳率 | 采纳次数 ÷ 调用次数 | 计算字段 |

> 🔍 **为什么"营收只算已完成"这么重要？**
> 面试官常问"你的营收口径是什么"。标准答案不是"求和 net_amount"，而是
> **"已完成状态的订单净额，剔除退货"**——因为本数据集含未完成订单与退货单，
> 若不剔除，营收会被虚增约 X%（可用 `透视预分析` 页与 `透视结果_月度趋势` 页对照看）。

## 4. 面试怎么讲（30 秒版）

> "我用 Excel 做了**三层**分析结构：底层是**明细数据表**（订单、商品、库存、商机、工单、营销、AI 七张事实表），
> 中间层是**公式透视层**（SUMIFS/COUNTIFS 预聚合，证明我懂透视表底层就是条件聚合），
> 顶层是**交互式数据透视表**（行/列/筛选/切片器 + 计算字段）。
> 关键是我做了**口径固化**：营收只算已完成且剔除退货，这个口径在 Excel 层、SQL 层、Power BI DAX 层、
> Tableau 计算字段层是**同一套**，所以四个工具出的数字可以互相印证——
> 这一点我用 `VerifyAgainstStatic` 宏和 `bi/verify_baselines.py` 做了自动化校验。"
